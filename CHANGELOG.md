# Changelog

## Unreleased

- 8.5: the Windows builds embed a version resource (`src/version.rc`; `version.h` now holds the version as major, minor and patch numbers, and `SKM_VERSION` is still 2.0.0), and the Makefile's Windows release executables are stripped (`-s`). F-Secure's real-time scanner had quarantined the unstripped `-O3` MinGW release build of 8.2j and later as `TR/W64.Evo`, a machine-learning false positive; the hardened Makefile and Visual Studio builds are clean in its on-access and on-demand scans. Program code, results, goldens and Linux builds are unchanged.

## v2.0.0 - 26-11-2026

Refactor of v1.0.0 for reproducible thesis experiments. Results differ from v1.0.0: the random stream changed in 1.5 and the algorithm fixes of Phases 2, 6 and 8 are listed below.

- 2.3: K=1 runs without a split (SKM variants and bisecting crashed with a heap overflow); the final k-means gives the dataset mean. SKM-Global and SKM-Global-Basic with K=2 now run global k-means after the initial split; before, they skipped it and reported SSE 1.7976931348623157e+308 (DBL_MAX). Golden: e04_tiny SSE DBL_MAX -> 0, e07_k2 SSE DBL_MAX -> 107718.06 (same as SKM-Intra); new edge case e01_k1 (SSE 14686.68 for every algorithm).
- 2.4: split selection considers only clusters with 2 or more points (SKM variants, Random Split, bisecting); exits with an error if none is left. Fixes the hangs on one-point clusters (SKM-Local on e04_tiny with K=3, bisecting on e02_k_equals_n). Golden files unchanged; bisecting joins the edge runs (7 new golden files).
- 2.5: RKM tracking rows report the CI of the best solution also when the first repeat stays best (they said NA); the perfect/failed partition snapshots are relabelled with the best centroids (they held the labels of the last repeat). Golden files unchanged.
- 2.6: the data and ground-truth parser rejects values that are not finite numbers ("1,5", "abc", "1.5x", nan, inf, 1e999; before, strtod read them as 1, 0, 1.5, NaN, Inf, Inf) and lines longer than 16383 characters (before, split into extra rows); errors give file, line and column. getNumDimensions removed. Golden files unchanged.
- 2.7: batch mode lists only *.txt files (folders and other files are ignored) and sorts them the same way on every OS: ASCII case-insensitive, then byte order (before, MSVC used _stricmp and MinGW/Linux strcmp, so pairing could differ between builds). list_files moved to platform.c with checked allocation; every plain dir/name join is checked (joinPath). STAT, MKDIR_OK and PRAGMA_MSVC removed. Golden files unchanged.
- 2.8: ASan and UBSan clean on all 108 regression runs (Windows, Visual Studio clang 22); CI runs make asan check and make ubsan check with gcc and clang, leak detection on. _Analysis_assume_ fallback and the sal.h include removed (unused). No code fixes were needed.
- Phase 3 (measurement, outputs, CLI; golden files unchanged, M1 matches M0): run times from a monotonic wall clock (QueryPerformanceCounter or clock_gettime(CLOCK_MONOTONIC); clock() was CPU time on Linux) that pauses while tracking; _log.csv rows are buffered and written after each run, with run and count columns (RS: the initial solution and each improvement only; RKM: one row per repeat; KM: one row per iteration); --track-progress, --snapshots, --track-inner and --no-track are separate; snapshot names give run, iteration and phase; run_config.txt; --decimal-comma; a strict CLI (--max-swaps, --repeats, --bisect-tries, --init, --first-run, --datasets, --batch, --version); subcommands ci, sse and gt-from-partition; report (summary, seminar tables and curves from finished batch folders) and dataset.txt in every dataset folder.
- Phase 3 review (golden runs unchanged, report golden files updated): report ends RS at the last SSE improvement of each run (was the first CI = 0) and needs its _log.csv rows; KM mean curves keep each finished run at its last state (they averaged only the runs still running, so they rose); sd NA for one run; gt-from-partition rejects short, long or non-integer label files (it computed centroids from a partial file and exited 0); run_config.txt has no host name and names the program without its folder; an empty --datasets list is an error; splitClusterGlobal checks its realloc.
- Phase 4 (modules; golden files unchanged, M2 matches M0): src/main.c split into util, dataset, metrics, kmeans, split, algorithms, baselines, tracking, report, experiment and cli modules (main.c only calls cliMain); the squared distance and nearest-centroid search are static inline in metrics.h, so they stay inlined across modules; make check also runs unit tests (tests/test_unit.c: parser, metrics, RNG, k-means, local repartition); Windows CI with MinGW-w64 and Visual Studio 2026. No result changes.
- Phase 5 (performance groundwork; golden files unchanged, M3a matches M0): flat dataset and centroid buffers, stable indexed cluster views and shared local two-means; benchmark and profiling baseline with MinGW and Visual Studio release builds. The fixed MinGW benchmark's sum of per-run minima fell from 7828 to 6234 ms; the benchmark sessions were separate and include timing noise. No algorithm changes.
- 5.5: `--max-iterations` adds an opt-in per-call k-means cap for diagnostics; Random Swap keeps its two-iteration limit and the default remains unlimited. Capped RKM snapshots preserve the best repeat's partition rather than reassigning it. Run configuration rejects different limits in the same folder; golden files unchanged.
- 6.1: SKM-Local recomputes touched means after both fixed-centroid repartition passes, including the first and final splits, then refreshes their split scores. Empty clusters retain their centroids. Fränti, Kaukoranta & Nevalainen 1997 §2.4, p. 3047; the 15 changed intermediate golden curve lines are listed in `results/M4/6.1-after/golden-changes.txt`.
- 6.1b: `--repartition` selects `inward` (new default; current cluster versus both children, including child-to-child moves), `inward-nonchild` (skips child points), or the previous two-pass `both`. Mode is recorded in run configuration. Fränti, Kaukoranta & Nevalainen 1997 §2.4, p. 3047, and CBModules `Remapping`; golden changes and the 100-run comparison are in `results/M4/6.1b-after/`.
- 6.2: SSE-selected Intra, Local and Global apply the best evaluated trial's centroids and labels instead of re-splitting with new seeds; Basic keeps its raw-seed comparison. Selected inner traces retain their evaluation timestamps, and the SSE split runner rejects a zero internal iteration limit. Fränti, Kaukoranta & Nevalainen 1997 §2.1, p. 3044, and CBModules `SplitPartition`; golden changes and milestones are in `results/M4/6.2-after/`.
- 6.3: bisecting runs all tries on every split and applies the best local centroids and labels without moving other clusters; final global k-means remains and restores its best scored state. Fränti, Kaukoranta & Nevalainen 1997 §2.3, p. 3046; Rantinoja 2023 §3.2, p. 24 (bisecting selection and tries). This is bisecting plus final refinement, not the unrefined variant. Golden changes and milestones are in `results/M4/6.3-after/`.
- 6.4: Random Swap compares the first candidate with the initial SSE, updates only affected means after local repartition, and scores the actual state after two k-means iterations. A non-finite initial SSE is an error; a non-finite candidate is warned and rejected. Per swap the order follows the step list of Fränti 2018, p. 7: local repartition, affected-mean update, then two k-means iterations (partition, then means). The [Random Swap pseudocode](http://cs.uef.fi/pages/franti/research/rs.txt) and CBModules `rs.c` instead run two iterations of means, then partition, without a separate mean update; the 2018 order was kept deliberately (2026-11-23). Fränti 2018, pp. 5-7; golden changes and milestones are in `results/M4/6.4-after/`.
- 6.5: all split-based algorithms and bisecting start from the dataset mean, without an initial random draw. Fränti, Kaukoranta & Nevalainen 1997 §2, p. 3043; golden changes and milestones are in `results/M4/6.5-after/`.
- 6.6: random initial representatives and split seeds have distinct coordinates; duplicate-only clusters cannot split, and K above the number of distinct points is rejected. Random Swap redraws targets equal to any current centroid, with a bounded uniform fallback; K equal to the distinct count makes every swap a no-op. Random Split redraws a cluster without two distinct points; after as many ineligible draws as there are clusters it picks an eligible cluster by rank (before 6.6 it redrew clusters with fewer than two points without a bound). The choice stays uniform over the eligible clusters, but the random sequence can differ from an unbounded redraw. Collision-free random initialization retains its Fisher-Yates draws. Fränti, Kaukoranta & Nevalainen 1997 p. 3049; Fränti & Kivijärvi 2000 p. 362 and the [Random Swap pseudocode](http://cs.uef.fi/pages/franti/research/rs.txt). Golden changes and milestones are in `results/M4/6.6-after/`.
- 6.6b: `--bisect-select sse|size` selects the largest eligible cluster by SSE or assigned row count; `sse` remains the default. Steinbach, Karypis & Kumar 2000, TR 00-034, p. 8 (size); Rantinoja 2023 §3.2, p. 24 (SSE). Mode-specific goldens and the paired comparison are in `results/M4/6.6b-after/`.
- 6.7 report fix: calculate SSE and time means and sample deviations from shifted values, so identical runs have their exact mean and zero deviation. The report golden at the pre-Phase-6 baseline changes s02 SKM-Random mean `11209188155.907171` to `11209188155.907173`; on the Phase-6 working tree, s02 SKM-Global-Basic changes `1376338486.203860` to `1376338486.203859`. No clustering results change.
- 6.7 comparison: reused the verified 6.6 and 6.6b results, ran all algorithms on the new DIM sets, and compared Local inward and both on 100 paired runs per dataset. Per-source reports and provenance-labeled comparisons are in `results/M4/6.7/`; no configurations or builds are merged.
- Phase 6 review: removed `splitClusterGlobalV2` and `tentativeSplitterForBisecting`, which had no callers since 6.2 (SKM-Global applies the scored trial split, then global k-means) and 6.3 (`runBisectingTrial`); updated doc comments that no longer matched the code (Random Swap step order and swap target, Random Split fallback, error conditions, inner-trace capture). Golden files unchanged; no result changes.
- 6b.1: KM and RKM wrappers and the Random Split runner reject a zero k-means iteration limit; local two-means asserts a positive limit. The CLI already rejected zero. Golden files unchanged.
- 6b.2: added runner-level tests for cached Global and Local splits, the split-seed fallback and Random Split's rank fallback; the tentative centroid pair uses designated initializers. Golden files unchanged.
- 6b.3: k-means reports the final iteration's SSE and state, including a non-improving final iteration; split trials save that state once, and bisecting still keeps the best try. RKM keeps the winning repeat's actual partition, copying it with the stopwatch paused. Non-finite KM/SKM final scores and Global-Basic trial scores now fail explicitly; Random Swap retains its last-state scoring and non-finite-candidate rejection, and the RKM no-finite-score fallback remains. This is the provisional D11 choice; Fränti & Sieranoja 2019 p. 95 describes convergence, while CBModules `KMeansIterate` keeps its final state. Golden files unchanged; all 5,825 paired M4 runs match their before SSE and CI.

- Phase 7 (performance tuning; golden files unchanged): reuse per-run k-means, initialization and local two-means scratch and RKM candidates; compute per-cluster SSE from stable dataset-order membership; remove the redundant Random Swap membership rebuild, split pre-partition and label copies, non-debug touched counting, and unused bisecting size-mode cluster SSEs. M3b matches `results/M3b-ref/` in all 63 run files and 4590 run/seed/SSE/CI rows; the benchmark and methods are in `results/M3b/`. No algorithm changes.

- 8.0a (D9): SKM-Local now defaults to `--repartition both`; `inward` and `inward-nonchild` remain selectable. The default adapts Random Swap's rejection-and-attraction rule to the two split children, rather than claiming that the RS sources specify this split procedure. `inward` retains the source-based comparison from Fränti, Kaukoranta & Nevalainen 1997 §2.4 and CBModules `Remapping`. The 6.7 comparison covers both modes on 100 paired runs per dataset. `golden-update` changed eight intermediate Local curve rows, but no final run goldens; the rows and new default-versus-explicit checks are in `results/M4/8.0a/`.
- 8.0b (D12): for K=2, all four SSE-split variants skip the two unused trial evaluations and their cache after the first split. No later random step uses the changed RNG state; K>2 trial evaluations remain unchanged. Debug level 3 no longer prints the unused trials. Golden files are unchanged after `golden-update`; paired scores, snapshots and timings are in `results/M4/8.0b/`.
- 8.2d: input-file reads and result-file writes, flushes and closes, including the line-length look-ahead, now report failures; directory enumeration and entry-inspection failures no longer silently return partial lists. Regression and benchmark tools also check file I/O. Failed calls can leave incomplete files; normal outputs and goldens are unchanged.
- 8.2e: `sse` exits with an error for a non-finite score. Per-call SSE means retain the ordinary sum-and-divide calculation, using a 2^-64 scaled accumulator only when the sum overflows; an unrepresentable fallback is an error. Goldens are unchanged.
- 8.2f: directory creation accepts existing paths only when they are directories; timestamp collisions with directories still use numeric suffixes. Clock, local-time conversion and timestamp-formatting failures now terminate explicitly.
- 8.2g: `gt-from-partition` sends empty-data errors and missing-label warnings to stderr. Informational stdout and generated centroids are unchanged; goldens are unchanged.
- 8.2h: selected dataset names and report dataset/display names reject semicolons, double quotes, CR and LF before runs or report output. Commas remain valid. `--names` is read once in binary mode to preserve CRLF handling and non-seekable input; goldens are unchanged.
- 8.2i (D15): RKM skips non-finite repeats with one post-timing warning per affected run, accepts a finite `DBL_MAX` winner, and fails without a result or orphan progress rows if no repeat is finite. Progress and report curves use `NA` before the first finite repeat. Goldens are unchanged.
- 8.2j (D16): record raw-byte SHA-256 fingerprints from the same input snapshots used for parsing. Appends and multi-folder reports require matching input identities and K; missing or malformed metadata is rejected. A single valid historical folder without fingerprints remains reportable with a warning and an unrecorded-identity marker. Goldens are unchanged.
