Step 6.6b bisecting-selection comparison, 2026-11-22

Both modes used the same MinGW release binary, seed 20261119, log level 1,
tracking rows, no selected snapshots, five tries per split and convergence
defaults. Every one of the ten main and hard datasets has 100 runs per mode,
including worms_2d. Runs 1-25, 26-50, 51-75 and 76-100 were executed in
alternating mode orders. Input hashes were checked before and after the
measurement; source and input hashes are retained alongside this file.

The previous 6.6 default-SSE run is the before milestone. The new explicit
SSE run matches its nine 100-run files and first ten worms_2d runs exactly.
The mode folders retain run_config.txt, per-run SSE and CI, dataset metadata,
and report tables with mean and sample SD of SSE and time, mean and relative
CI and success rate. paired-comparison.csv compares size with SSE on
matching run indices and seeds. Different selected clusters can consume
different random draws, so paired seeds do not imply identical random streams.
Timing differences include machine and ordering noise.

Size uses the assigned row count, including duplicates, among clusters with
at least two distinct coordinates. This is a Steinbach-inspired selection
rule, not an exact reproduction of the original cosine-based algorithm.
