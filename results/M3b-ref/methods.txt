The default folder explicitly uses inward repartition and SSE-based
bisecting. On s1, s4, a3, unbalance and dim064, KM, Random, Intra,

bisecting; Global, RKM and RS are omitted. local-both holds Local with
both repartition, and bisect-size holds bisecting with size selection:
each has 100 runs on the five small datasets and 10 on worms_2d.

The 63 run files contain 4590 runs. Each mode has its own run_config.txt
and report; progress rows remain in the full run folder, so report can
end RS times at the last SSE improvement. Dataset metadata and reports
were copied byte-for-byte with the run files. All 21 input hashes were
checked after the runs; birch1's three files are for the benchmark only.
